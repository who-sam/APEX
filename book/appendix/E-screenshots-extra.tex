\chapter{Screenshot Capture}
\label{appendix:screenshots-extra}

This appendix documents the seed data set and the capture procedure used to produce the screenshots in \Cref{ch:user-manual}. The convention is to capture against a freshly-seeded local instance so the screenshots can be reproduced from source without exposing real student data.

\section{Seed data set}

\begin{itemize}
  \item Two users: \texttt{teacher@demo.test} (role \texttt{teacher}, password \texttt{demo-pass}, display name \emph{Dr.~Demo}) and \texttt{student@demo.test} (role \texttt{student}, password \texttt{demo-pass}, display name \emph{Sam Student}).
  \item One class: \emph{Demo CS101}, invite code \texttt{ABCD1234}, with Sam enrolled.
  \item Three exams assigned to the class:
    \begin{itemize}
      \item \emph{Sum Two Numbers} (coding) --- one Python problem with three test cases (one sample, two hidden), 30-minute duration, 60-minute window.
      \item \emph{Time Complexity Quiz} (MCQ) --- four single-correct questions, 10-minute duration.
      \item \emph{Discuss Recursion} (written) --- one question with rubric, 200-word maximum.
    \end{itemize}
\end{itemize}

\section{Seeding procedure}

\begin{enumerate}
  \item Bring up the system: \texttt{./start.sh}.
  \item Sign up Dr.~Demo through the SPA.
  \item Sign up Sam Student through the SPA.
  \item As Dr.~Demo: create the class, copy the invite code.
  \item As Sam: join the class with the invite code.
  \item As Dr.~Demo: build the three exams using the screenshots in \Cref{ch:user-manual} as a guide; assign each to the class; publish each.
\end{enumerate}

\section{Capture conventions}

\begin{itemize}
  \item Window size 1440$\times$900, browser zoom 100~\%, dark devtools off.
  \item Crop the browser chrome but keep the OS-native title bar out of frame.
  \item Strip PII: only the seeded names appear; the email-server logs are not screenshot.
  \item Save as PNG in \texttt{book/figures/screenshots/} with the canonical filename \texttt{F9.X\_<slug>.png} matching the figure label in \Cref{ch:user-manual}.
\end{itemize}
